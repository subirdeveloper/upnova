# Hostinger deployment preparation

The prepared Upnova website is static. Node.js is used during the build; the deployed site needs no continuously running Node server.

**The source upload is pending.** These notes describe the intended deployment once the full source and assets are present.

## Build and deployable files

Run `npm test`, `npm run build`, then `npm run check`. The deployable files are the **contents of `dist/`**, with `index.html`, `assets/` and course folders directly inside the target website directory.

Do not deploy this repository root as a working website. It currently contains setup files only, and the website entry point will be generated by the build after the source upload.

## Git deployment

Hostinger's static Git integration needs a branch whose root contains the generated website files. Keep editable source on `main` and use a separate `hostinger` branch for the built output.

Confirm that the hosting plan supports Git deployment for a custom HTML site. The target folder, such as `public_html`, is a destination directory rather than a build-output setting.

Before connecting auto-deployment to the existing Upnova website directory, obtain replacement approval and verify a backup. A push to a connected deployment branch can trigger a hosting update.

## Staging and launch

A private GitHub repository and `noindex` do not protect a separately hosted staging website. Configure hosting-level access control before uploading a private review.

Before an approved public launch:

1. Verify the desktop/mobile experience, including the 3D fallback, keyboard controls, course links and reviewed enquiry handoff.
2. Confirm course details, policies, contact information and internship terms with Upnova.
3. Update the production origin, canonical URLs, structured data, indexing metadata, robots rules and sitemap together.
4. Review the hosting/privacy text, which currently describes the private Sites preview.
5. Configure the approved domain and HTTPS and verify root/www redirects.

Publishing repository setup does not configure Hostinger, change DNS, replace WordPress, enable GitHub Pages or launch the website.
