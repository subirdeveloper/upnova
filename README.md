# Upnova Institute — Make Your Next Move

Interactive learning website for Upnova Institute, with an actual Three.js sculpture, four course paths, creative exercises, FAQs, internship guidance and a reviewed WhatsApp enquiry draft.

## Upload status

Repository setup has been published. **The website source and assets have not been uploaded yet.** The prepared export is currently in an unavailable source workspace. This repository does not yet contain a runnable website.

The prepared export previously passed 10 core logic tests and generated-page checks for 13 pages and 257 internal links. Those checks describe the prepared export, not a GitHub Actions run or a verified deployment from this repository.

## Build commands after the source upload

Use Node.js 24. The prepared build uses no package dependencies.

```sh
npm test
npm run build
npm run check
```

The generated website will be in `dist/`. Deploy the **contents** of that directory, with `index.html` and `assets/` at the website root.

## Hosting

See [HOSTINGER.md](HOSTINGER.md). Publishing source here does not deploy a website to Hostinger, configure DNS or enable GitHub Pages. The existing Sites deployment and custom domain have not been changed.

The prototype retains search-engine exclusions and its existing Sites canonical URL. Production indexing, domain configuration, hosting/privacy text and device validation need a separate launch review.

Enquiries remain local drafts until a visitor explicitly opens WhatsApp and chooses to send the message. No lead database, analytics or payment service is connected.

The completed source export is intended to include the original Upnova logo, local font and local Three.js modules with their licence notices. This repository does not grant a licence to reuse institute-specific branding or content.
